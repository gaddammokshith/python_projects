# Python Projects

This repository contains simple Python mini projects created using Python for practice and learning.

## Projects Included

### 1. Rock Paper Scissors Game
This is a simple Python-based Rock Paper Scissors game where the user plays against the computer. The program takes the user’s choice as input and randomly generates the computer’s choice using Python’s `random` module. It then compares both choices and displays whether the user wins, loses, or draws the game.

### 2. Hangman Game
This is a simple Python-based Hangman game where the user guesses letters to find a hidden word. The program randomly selects a word, tracks the user’s lives, and displays hangman stages based on wrong guesses.

## Technologies Used

- Python
- Random Module
